

# Gumbo

Inspired by Joan Didion's thanksgiving dinner parties highlighted in this [article](https://www.nytimes.com/2025/11/18/dining/joan-didion-thanksgiving.html), Gumbo inspires the creation of well thought out potlucks and dinners.

Gumbo features a seating-arrangement creator using NLP, private links for guests and hosts ran on firebase and more.

User interface is simple and rooted in the design of Didion's letters.

Photos from a friend :). Still working on testing + doing for fun.

# Pages
Launch:
- User inputs event information including a "meaningful question" and potluck or dinner preferences. 
Home:
- See guest list.
- Copy and paste guest rsvp link and private host link.
The Invitation:
- Edit your invitation image and event details.
The Making:
- View seating arrangements (only works after more than 2 guests rsvp)
  - Seating arrangements show similaraties of answers to the "meaningful question". User can either pair       those who have similar answers or pair those who have differing answers. 
- To-do list
- Menu *indicates whether there is enough food for all guests who RSVP'd.
The Potluck:
- Shows which guest will be bringing each item.

Invitation and RSVP -Guest Side-:
- User answers questions and gets individual link to edit rsvp response.
